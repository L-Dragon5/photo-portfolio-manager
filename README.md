# Personal Photo Portfolio Manager

Built on Laravel 12, React 19, Inertia.js, and Mantine 8, with media handled by Spatie Media Library and stored on AWS S3. Deployed to Fly.io.

Allows easy uploading and managing of photos for my own personal use.

Previous site was developed in Gatsby. Worked well, but ran into issues having to constantly rebuild the site whenever adding new photos.
